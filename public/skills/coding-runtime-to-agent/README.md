# Coding runtime to agent, public bundle

Turn a coding CLI (Codex, Claude Code, Kimi, etc.) into a named teammate with a stable personality, honest memory rules, and a safe agent-to-agent front door. Four layers: identity, memory policy, a consultable entry point, and proof. Packaging, not magic: the runtime is the body; you add the soul.

Pairs with the coding-runtime-personas skill for safe identity/continuity rules.

## Install

```bash
curl -sSf https://superada.ai/install/coding-runtime-to-agent | sh
```

Or copy `SKILL.md` into your agent skills directory (for OpenClaw: `~/.openclaw/skills/coding-runtime-to-agent/`).

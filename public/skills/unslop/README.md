# Unslop — public bundle

A compact 31-pattern anti-slop editor: cut AI tells from any writing and add human voice (opinions, varied rhythm, allowed mess, specific feelings). Covers content puffery, AI vocabulary, em dash/colon/bold overuse, chatbot phrases, filler, abstract jargon metaphors, and plain-speech fixes.

## Install

```bash
curl -sSf https://superada.ai/install/unslop | sh
```

Or copy `SKILL.md` into your agent's skills directory (for OpenClaw: `~/.openclaw/skills/unslop/`).

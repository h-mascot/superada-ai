What shipped in 2026.5.20

Release bullets worth saying out loud

  • Discord voice sessions can now follow configured users into voice channels, handle multi-user handoff, keep allowed-channel checks, and preserve DAVE recovery.
  • Doctor now warns when openclaw.json stores plaintext secrets like provider API keys or sensitive headers, so config cleanup is visible before it becomes a bad day.
  • Status is clearer when a session is pinned to a different model than your default: it shows the configured default, selected model, reason, clear hint, and docs link.
  • xAI login is easier on headless and remote machines: device-code OAuth lets you authorize without depending on a localhost browser callback.
  • Windows installs no longer visibly freeze at Starting setup..., and managed updates keep using the Gateway service Node instead of silently switching Node binaries.

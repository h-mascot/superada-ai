Community signal

Users still feel the setup tax

  • People are mixing runtime, provider auth, selected model, channel session, and memory behavior. The product makes those seams visible all at once.
  • Claude CLI / Max plan setup and ChatGPT Pro / Codex OAuth confusion kept surfacing.
  • Upgrade anxiety is real: some users praised 5.18/5.19, others reported broken setups and downgrade pressure.
  • The fix is not “more docs” generically. It is canonical setup paths and clearer status when reality diverges from expectation.

Channel reliability

Telegram and chat surfaces are still high-leverage

Follow-up ask

Make repro asks narrow

  • For auth/model issues: ask for provider, runtime, selected model, auth profile, and exact status output.
  • For Telegram/topic bugs: ask for channel type, topic id, message id, timestamp, and whether generated media/progress was involved.
  • For voice/browser issues: ask for transport, platform, modal/dialog state, and one reproducible action.

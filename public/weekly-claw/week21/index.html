Trust boundaries

Secret egress host binding

  • Ties shared-store secrets to exact HTTPS destination hosts
  • Fails closed before any plaintext egress

Developer experience09 / 12

v2026.8.1-beta.2 verification

DX review

The release notes are direct about what passed and what didn't ahead of promotion.

What passed

  • Packaged Telegram, Docker assets, clean install and update
  • Plugin runtime checks and targeted Docker lanes
  • An isolated live model turn

What did not

  • Full Release Validation did not pass
  • An unbound context-engine session could fall back to the default agent
  • Release tooling and test fixtures also failed

Guidance from the release

  • Don't promote this beta to stable without a fixed successor
  • Don't promote without green full validation
